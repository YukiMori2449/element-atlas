# ELEMENT ATLAS

日本語で118元素を学べる周期表。ホバー・タップ・キーボード操作、検索、分類フィルター、写真・電子殻模式図、電子配置と物性データを備えています。

## 開発

Next.js 16 / React 19 / TypeScript / Tailwind CSS 4 で構成しています。

Node.js 22以降で次を実行します。

```bash
npm ci
npm run dev
npm run build
```

VercelではFramework Presetを `Next.js`、Root Directoryをリポジトリ直下に設定します。ビルドコマンドと出力先はVercelの自動設定を使用し、環境変数は不要です。

## データ

- `data/elements.json`: 表示用データ。日本語説明は本サイト用に編集。
- 物性・電子配置: Royal Society of Chemistry の元素別ページ（各レコードの source）。取得日: 2026-09-07 JST。
- 元素の配置・画像情報: Bowserinator/Periodic-Table-JSON、CC BY-SA 3.0。日本語化・加工データも CC BY-SA 3.0。
- 写真は各レコードの attribution に著作者とライセンスを記載。Chemical Elements — A Virtual Museum の写真は各元素ページへリンクする CC BY 3.0。
- 密度の単位は g/cm³。RSCの室温付近の値。温度・圧力・同素体によって変わります。
- 原子番号85、87、100以降の未確立の密度・融点・沸点は予測値を表示せず「不明」。RSCでUnknownとされた値も「不明」。炭素・ヒ素は常圧での昇華を注記。
- 超重元素の電子配置は予測であることを表示。実物写真のない元素は電子殻の模式図を表示します。模式図は縮尺・量子力学的な軌道を表すものではありません。
- 電子殻の個数はRSCの電子配置から集計。

## 固体元素の磁性

- `data/magnetism.ts`: 磁性分類、結晶相、基準温度、磁気転移、温度による変化、および出典の対応を管理。確認日: 2026-10-26 JST。
- 基準は25℃（298.15 K）・常圧・純元素のバルク固体。CRC 84版の室温データは285–300 Kの代表値で、厳密な25℃の測定値ではないことを表示。
- 強磁性・反強磁性・常磁性・反磁性を区別。Crは25℃で反強磁性、Gdは25℃で常磁性。正の磁化率だけでCrを常磁性に分類しない。
- 相を区別: Snは通常の白色β相の常磁性を表示。灰色α相の反磁性は注記。Ceは室温γ相を分類し、β相の12.5 K転移は別相の値として明示。
- 磁気転移にはキュリー点・ネール点・確認済みの再配向や秩序化を掲載。Tmの低温フェリ磁性、Erの多段階転移も注記し、4分類へ無理に丸めない。
- 出典を確認できない分類・温度変化・転移温度は「不明」。空の転移配列は未確認を意味し、転移が存在しないことを意味しない。電子配置や隣接元素から磁性を推定しない。
- 液体・気体の磁性を固体に転用しない。元データの状態は20℃であるため、25℃での相を断定できないFrを例外扱いする。
- 超伝導・高圧・薄膜・ナノ粒子・合金の相図を網羅するものではない。磁場、結晶相、試料純度、応力などによる差に注意。
- 磁性の出典は物性データの従来出典から分離し、各元素の磁性欄と各転移にリンク。原典PDFや論文本文は再配布せず、事実の分類と日本語での要約を掲載。

データ整合性と科学的な例外は `npm run check:data` で検証します（Node.js 22.13以降）。

## 操作

PC: ホバー・Tabで元素の詳細を確認。クリック・Enter・検索結果の選択で固定し、他の元素へカーソルを移しても選択を保持。「固定解除」でホバー・Tabでの確認に戻る。別の元素をクリックすると固定対象を切り替える。

スマホ: 元素をタップで詳細ダイアログ。閉じるボタン・背景・Escapeで閉じる。横にスクロールして18族すべてを表示。
